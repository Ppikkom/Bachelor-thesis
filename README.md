# Percolation Simulation
[한국어](./README.md) | [日本語](./README.jp.md)
## 📌 프로젝트 개요

2차원 및 3차원 격자 시스템에서 사이트 퍼콜레이션과 본드 퍼콜레이션을 시뮬레이션하고,
임계확률과 클러스터 형성 과정을 분석한 C++ 기반 연구 프로젝트입니다.

퍼콜레이션 이론은 일정 확률로 연결된 격자 구조에서 전체를 관통하는 연결 경로가
형성되는지를 분석하는 이론입니다. 본 프로젝트에서는 이를 전기 전도성과 연결하여,
전류가 흐를 수 있는 경로가 언제 형성되는지 확인했습니다.

## 🧪 연구 목표

- 2차원 사이트 퍼콜레이션 분석
- 2차원 본드 퍼콜레이션 분석
- 3차원 사이트 퍼콜레이션 분석
- 3차원 본드 퍼콜레이션 분석
- 각 모델의 임계확률 비교
- BFS와 Union-Find를 활용한 클러스터 탐색 및 연결성 판정

## 🛠 사용 기술

- C++
- BFS
- Union-Find
- Monte Carlo Simulation
- Random Number Generation
- File Output

## ⚙️ 시뮬레이션 과정

1. 격자 시스템 생성
2. 사이트 또는 본드를 확률적으로 활성화
3. 클러스터 탐색
4. 시작 지점과 끝 지점이 연결되는지 확인
5. 퍼콜레이션 발생 여부 판정
6. 여러 확률값에 대해 반복 실험
7. 임계확률 추정

## 🔍 핵심 알고리즘

### BFS

활성화된 사이트 또는 본드를 기준으로 인접한 요소를 탐색하여
하나의 클러스터를 구성하는 데 사용했습니다.

### Union-Find

여러 노드 간의 연결 관계를 효율적으로 관리하고,
시작 영역과 끝 영역이 같은 집합에 속하는지 확인하는 데 사용했습니다.

## 📊 결과

시뮬레이션을 통해 다음과 같은 임계확률을 확인했습니다.

| 모델 | 임계확률 |
|---|---:|
| 2D Site Percolation | 약 0.5927 |
| 2D Bond Percolation | 약 0.5 |
| 3D Site Percolation | 약 0.31 |
| 3D Bond Percolation | 약 0.25 |

2차원보다 3차원 시스템에서 더 낮은 확률로 퍼콜레이션이 발생했습니다.
이는 3차원 구조가 더 많은 연결 경로를 가질 수 있기 때문입니다.
