# C++ Percolation Simulation
[한국어](./README.md) | [日本語](./README.jp.md)
## 📌 概要

二次元および三次元格子におけるサイトパーコレーションとボンドパーコレーションをシミュレーションし、
臨界確率およびクラスター形成の過程を解析した C++ プロジェクトです。

パーコレーション理論とは、一定の確率で構成された格子において、
全体を貫く連結経路が形成される現象を扱う理論です。

本プロジェクトでは、この現象を電気伝導モデルとして再現し、
電流が流れる経路がどのような条件で形成されるのかを解析しました。

---

## 🎯 目的

- 二次元サイトパーコレーションの解析
- 二次元ボンドパーコレーションの解析
- 三次元サイトパーコレーションの解析
- 三次元ボンドパーコレーションの解析

## ⚙️ シミュレーションの流れ

1. 格子を生成
2. サイトまたはボンドを確率的に生成
3. クラスターを探索
4. 始点と終点が連結しているか判定
5. パーコレーション発生の有無を判定
6. 各確率に対して多数回シミュレーションを実施
7. 臨界確率を推定

---

## 🔍 実装アルゴリズム

### BFS（Breadth-First Search）

活性化されたサイト（またはボンド）を探索し、
一つのクラスターを構成するために使用しました。

### Union-Find

ノード同士の接続状態を効率的に管理し、
開始地点と終了地点が同じ集合に属しているかを高速に判定しました。

---

## 📊 実験結果

シミュレーションにより以下の臨界確率を確認しました。

| モデル | 臨界確率 |
|------|------:|
| 2D Site Percolation | 約 0.5927 |
| 2D Bond Percolation | 約 0.50 |
| 3D Site Percolation | 約 0.31 |
| 3D Bond Percolation | 約 0.25 |

三次元システムは二次元よりも接続経路が多いため、
より低い確率でパーコレーション状態に到達することを確認しました。
